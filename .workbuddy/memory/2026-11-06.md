## 老师建议 + 我的处理
老师的三个方向（数据增强 / 优化器超参 / 参数量化）都成立；但**"换个不是 best 的 ckpt"有一个陷阱**：
- ❌ 用平台分回头挑 ckpt = 规则第 5 条明令禁止的「不得用于 checkpoint 选择」。
- ✅ 合规替代：**相邻轮次权重平均**（checkpoint averaging / SWA），不用任何测试信息，
  且理论上更抗分布偏移（EMA 相邻轮相关性 >0.99，平均能压掉权重噪声）。
- 我们手上就有 `baseline1/runs/*/ema_f{epoch}.pth`（train.py 每轮都存），零成本可做。

## large384 平台回分 77.37（低于双模型 77.67）
四次提交的落差（valid×100 − 平台）：
| 模型 | valid | 平台 | 落差 |
|---|---|---|---|
| soup 旧 | 0.7977 | 76.91 | 2.86 |
| full_base | 0.7997 | 76.88 | 3.09 |
| **双模型集成** | 0.8027 | **77.67** | **2.60** |
| large384 | 0.8059 | 77.37 | **3.22** |
落差均值 2.94、sd 0.27、极差 0.62 → **单点换算误差 ±0.3~0.4，够把 77.7 的预测打成 77.37**。

关键发现：**落差随模型容量/valid 升高而变大**（2.86→3.09→3.22），唯独集成最小（2.60）。
→ 支持"赢家诅咒"解释：单模型 valid 峰值是"挑出来的"，越高越可能是运气；集成平均压低噪声，valid 更可信。
→ 结论：**valid 上 0.003~0.006 的单模型差距无法预测平台**；large384 确实优于单 base（+0.49）但不敌集成（−0.30）。
→ 规划口径修正：单模型要稳过 77.7 需 valid ≥ **0.809**（按落差 3.2）；集成形态按 2.6 只需 0.803。
→ 战略含义：后续改动应加在"平台已验证 77.67"的双模型形态上（277MB，余量 220MB），
  而不是继续用更大单模型追 0.005 级 valid 差。

## 老师第二轮建议的评估（文档：老师建议评估_1106.md）
老师给了 6 个方向：MLLM 打标签扩数据 / 扩充微调数据 / 数据增强 / 为什么不用 ResNet+ImageNet /
Ensemble+MoE / 9 个单病种小模型再集成。

判定（逐字复核 规则.md + 规则补充.md 后）：
1. **MLLM 造标签**：属知识蒸馏，教师须开源、非 gated、非医学主数据集（补充三）。医学 MLLM 直接禁；
   GPT-4V 类闭源 API 不满足"开源/非 gated"；仅开源通用 VLM 勉强可申报，但 VLM 在胸片细粒度上很弱，
   且官方无未标注图可扩 → **不做**。
2. **生成式合成胸片**：合成图仍是"非赛方提供的医学图像"，违反第 2 条 + 补充五；且生成模型多基于
   医学数据训练，叠加违反第 1 条 → **不做**。区分：变换同一张图=允许（第 4 条），生成新图=违规。
3. **数据增强**：第 4 条明确允许（含离线预生成）。我们只用 mild，strong/Mixup 从未跑 → **第一优先**。
4. **ResNet**：误解点——我们一直用 ImageNet 权重，只是选了 ConvNeXt(84.1%)/EffV2(85.0%) 而非
   ResNet50(80.9%)。ResNet 的价值在"归纳偏置不同"→ 作集成第三成员（51MB，+5ms）→ **值得做**。
5. **Ensemble**：同架构 +0.0021 / soup +0.0004 / 跨架构 +0.0030 → 继续但换"更不像"的成员。
   **MoE**：30k 数据撑不起路由（易坍塌）+ 体积耗时 → 不做；折中=共享骨干+每类小专家。
6. **9 个独立小模型**：合规、体积耗时都够，但等价于丢掉"共享骨干"的多任务优势；其唯一潜在收益
   （per-class 采样）我们已实测为负（平衡采样 −0.0086、pos_weight +0.0001）→ 不推荐整模型级拆分。

合规替代（用官方数据扩"监督信号"而非"数据量"）：A 同 study 多图作正样本对/一致性正则
（标签一致性已实证）B ViewPosition 辅助任务（零推理成本，CXR-LT 银牌背书）C 强增强+Mixup。

修正一个口径：参数量化（INT8）不解决分数，且补充九(三)要求排序不得变，量化改变排序即判不一致 →
当前 277MB/42ms 都有余量，量化无收益只有风险。
