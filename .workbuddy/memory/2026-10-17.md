## 深夜修复（Mac 冒烟测试暴露的两个真 bug，已修复并验证）
1. **TTA 亮度变换不可 pickle**：`make_tta_tfms` 里嵌套函数 `scale_brightness.<locals>.apply_fn` 无法被 pickle，macOS/spawn 的 DataLoader worker 直接崩（Linux fork 不暴露）。修法：提到模块级 `_scale_brightness_impl` + `functools.partial` 包装。6 种 TTA 现已全部可 pickle。
2. **Dataset 返回结构可变导致 id 被污染**：`with_labels=True` 时 `__getitem__` 第二元素返回标签张量而非 Dicom_id，predict 在 valid split 上把标签当 id 存进 npz（dicom_ids 变成 (8,10) float32），ensemble 对齐必挂。修法：统一返回 `(img, dicom_id, labels)` 三件套，labels 推理时用零向量占位；train/predict 4 处循环解包同步改；ensemble 的 id 比较加 `str()` 兜底。
3. 配套：ensemble.py 增加 `--limit`（与 predict 对齐），Mac 冒烟链完整闭环。
4. **已验证（本机 CPU）**：train --limit 64 → predict --limit 8 --tta → ensemble --limit 8 → submission.csv 40 行自检通过。GPU 机上只需把 limit 去掉正式跑。
5. 提醒：runs/mac_smoke/ 下有约 1.7GB 冒烟权重（model_f1.pth 含优化器状态约 1GB），验证完可删。
