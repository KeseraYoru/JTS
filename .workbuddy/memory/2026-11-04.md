## 双模型 cost 实测 + 一个重要修复
- 实测（bal 训练争用中）：**64ms / 不一致 0 张**。一致性已通过 → 77.67 的可交付性第一步成立。
- **发现重复劳动**：cost.py 原先对每个模型各读一次原图 → 同一张 2500px 图被 draft 解码 + resize 了 N 遍。
- 已修：`inference.py` 新增 `predict_one_path_multi()`（读图+预处理只做一次，张量喂所有模型），
  `cost.py` 的预热与计时都改用它。**预测结果数学等价**（线性均值交换顺序，误差 ~1e-8）。
- ⚠ 纠正此前承诺的补救①：「draft 直接解到 img_size」**没用**——draft 只会取 1/2、1/4、1/8 档位，
  448 和 600 都落到同一档（2500/4=625），所以省不了解码。真正的省法是共享预处理。
- T4 风险仍未消除：若共享后约 40ms，则 T4 ≈ 19×1.5 + 21×3.8 ≈ 108ms，**仍贴线/超限**，
  需要无争用复测后再定；备选是双模型降 384px（前向 ×0.735）。

## ⛔ 类别平衡采样失败（full_bal）
- 配置：单卡 GPU0 + **batch 8** + `--balanced-sampler 0.5`，12 轮，约 2h。
- 结果：峰值 **0.7844**（full_base 0.7997，**−0.0153**）；**类 1 = 0.6056**（原 0.6904，更差）。
- 其他类也普遍下滑：类2 0.8279→0.7626、类8 0.7124→0.6991、类7 0.7929→0.7723。
- 机制：`WeightedRandomSampler` **有放回**采样 → 每轮看到的**独立图片数变少**（等效数据缩水），
  且罕见类那几百张被反复抽到 → 对这几张**过拟合**，泛化更差。加权并不能制造新信息。
- ⚠ 混淆变量：本次同时把 batch 从 32 降到 8（受 mtt 占卡所迫），无法完全分离两者贡献。
  对照方案：补跑 `--batch-size 8` 的**无采样**基线（runs/full_b8），再与 full_asl(batch8) 比。
- 判决：**不再尝试调 alpha/cap**。罕见类不能靠重复抽样解决。

## 共享预处理后复测（无争用，仅 mtt 在跑）
- 双模型 448：**42ms / 0 张不一致**（改前 64ms，省 22ms = 一次重复解码）
- 单模型 convnext 448：**28ms / 0 张**
- 拆解：CPU(decode+resize+python) ≈ 21ms；convnext 前向 ≈ 7ms；**effv2m 前向 ≈ 14ms（是 convnext 两倍）**
- **T4 推算 @448 双模型 = 21×1.5 + 21×3.8 ≈ 111ms → 超限风险坐实**
- @384 双模型 ≈ 20×1.5 + 15.4×3.8 ≈ **88ms**（贴线，悲观假设下仍会超）
- 已给 `predict.py` / `cost.py` 加 **`--img-size` 覆盖参数**：可用 448 训好的权重直接在 384 推理，
  实测精度损失（A0/A5 曾证明 384 与 448 训练精度相当，但「448 训、384 推」尚未验证）。
- 若 384 仍不安全：换更快的第三架构（efficientnet_v2_s，前向约为 m 的一半），或租 T4 实测一次。

## batch 对照跑完（重要：把两个混淆变量分开了）
| 配置 | 峰值 | 相对 full_base |
|---|---|---|
| full_base（4卡 batch32） | 0.7997 | — |
| **full_b8（单卡 batch8，无采样）** | **0.7930** | **−0.0067** |
| full_bal（单卡 batch8 + 平衡采样） | 0.7844 | −0.0153 |
→ **batch 32→8 代价 −0.0067；平衡采样在这之上再 −0.0086**。平衡采样确认为负收益，彻底关闭。
→ **新基准：以后任何单卡 batch8 的实验必须和 0.7930 比，不能再和 0.7997 比。**
- 附带发现：batch8 的类 1 反而更好（0.7042 vs 0.6904），代价是类 2 大跌（0.8279→0.7914）。
  小 batch 的噪声梯度可能对罕见类有利、对中等类有害。
- 推断：若将来必须用 batch8，应同步按线性缩放把 LR 降到 1/4（本次没做，可能就是这个代价的一部分）。

## 下一步主线：convnext_large 单模型（同时解两个约束）
