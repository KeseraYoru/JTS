## 二、数据：我们实证知道了什么（这一节是老师最可能感兴趣的）

| # | 结论 | 证据 | 对建模的影响 |
|---|---|---|---|
| 1 | **提交单位是"检查"不是"图"**：1414 检查 / 2218 图 | test.csv 结构 | 必须做 study 级聚合（我们取均值） |
| 2 | **标签是 study 级**：同一检查所有图共享标签 | 18513 个多图检查中标签不一致数 = **0** | 可以按图训练，不损失信息 |
| 3 | **"无异常"与其余 9 类严格互斥** | 含类10 的行 = 纯类10 的行 = **12649** | ① Macro 里类10 ≈ "正常/异常"判别；② 可做 Normal Gating 后处理 |
| 4 | **极度不均衡，14 倍** | 类1: **894**（2.95%）→ 类10: 12649 | 类1 是 Macro 的短板（现 0.69，其余 0.72~0.91） |
| 5 | **无缺失标签** | 全表无空 Predict_class | 不需要处理"未提及"语义 |
| 6 | **划分干净，无泄漏** | subject 与 study 均无交叉；study_id 分段（train 0~19999 / valid 20000~20937 / test 20938~22437） | 验证集可信；也解释了为什么 test 与 valid 分布有偏移 |

## 三、做过的全部实验（20 组，带判决）

### 3.1 有效的（3 条）

| 实验 | 结果 | 说明 |
|---|---|---|
| **官方数据自监督预训练**（SimCLR，规则允许） | **+0.0258**（探针实测） | 增益集中在最弱的类：类1 +0.056、类4 +0.037、类3 +0.034 |
| **跨架构集成**（ConvNeXt + EfficientNetV2） | **+0.0030**（valid），平台 +0.79 | 逐类互补：effv2m 强在类2/3/9，convnext 强在类6/7 |
| **补全训练数据**（20% → 全量） | +0.0047 | 五折只用了 80% 数据 |

### 3.2 无效的（11 条，每条都花了真实 GPU 时间）

| 实验 | 结果 | 结论 |
|---|---|---|
| 分辨率 384→448 | +0.0004 | 源分辨率封死 |
| SSL 200 轮（vs 50 轮） | +0.0012 | 50 轮即饱和 |
| study 聚合 max / 混合 | max −0.0023 | 均值已最优 |
| pos_weight 上限 10→20 | +0.0001 | 峰值不动 |
| 同架构 5 折集成 | +0.0021 | 相关性太高，放弃蒸馏 |
| 类别平衡采样 | **−0.0086** | 有放回采样 → 独立图变少 + 罕见类过拟合 |
| ASL 损失 | **−0.0045** | 同 batch 对照，仍负 |
| batch 32→8（未缩放 LR） | **−0.0067** | 教训：LR 必须随 batch 缩放 |
| data1024 换源 | +0.0024 但推理 +40ms | 净亏，放弃 |
| DINOv2 ViT-B/14（网页自监督，合规） | 线性探针持平、微调 −0.035 | 30k 图低于自监督生效阈值，且 ViT 小数据易崩 |
| ConvNeXt-V2 | **未跑**：权重 CC BY-NC，规则一票否决 | 合规审查救了一次 |

### 3.3 工程侧的硬成果

- 推理链路统一后 **48ms → 26ms**，且预测与提交**逐张一致（0 张不一致）**；
- 双模型共享预处理：**64ms → 42ms**（同一张原图原来被解码两遍）；
- 定位到一个"假读数"：早先 16ms 是用 600² 小图测的，官方核验读 2500×3056 原图 —— 差点带着假数据交付。

## 五、想请老师帮的三件事（按价值排序）

1. **显卡协调**：4×5090 不是独占（另一位同学的 Pythia 训练长期占 4 卡），我们只能单卡 batch16。若能协调出 2~3 个"完整 4 卡小时"，关键实验能从 2 小时压到 25 分钟。
2. **技术判断**：30k 图 + 禁医学预训练，老师认为天花板在哪？我们估 79~80（现 77.67）。
3. **临床线索**：类1「纵隔心影增大」只有 894 正样本、AUC 卡 0.69。临床上有没有可转成模型先验的判读技巧（心胸比、纵隔宽度）？我们试过的加权/重采样/换损失全部无效，说明缺的不是训练技巧而是判读线索。
